## 2. Cluster capability detection

Added automatic detection of OCP, Gateway API, and Kuadrant versions on the target cluster, with feature "gating" so the converter never emits YAML the target cluster can't apply (issue #34). Hardened this week against slow/unreachable clusters: soft timeout with graceful fallback, coalescing of concurrent detect calls, and replacing expensive cluster-wide CSV listings with a targeted namespace probe + CRD check.
